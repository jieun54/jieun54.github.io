# jieun54.github.io

Personal academic website of Ji Eun (Jinny) Kim, built with Jekyll and hosted on GitHub Pages.

Most content lives in small data files:

| What | File |
| --- | --- |
| Name, role, links, photo | `_config.yml` |
| Bio | `index.md` |
| News | `_data/news.yml` |
| Publications | `_data/publications.yml` |
| Research themes | `_data/themes.yml` |
| Talks | `_data/talks.yml` |
| Colors and fonts | `assets/css/style.css` |

Preview locally:

```sh
bundle install
bundle exec jekyll serve
# open http://localhost:4000
```
